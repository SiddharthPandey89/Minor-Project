# Earth / GeoIntelligence Intelligence Platform

Structure-only repository skeleton for a future full-stack geospatial intelligence platform. It separates the React frontend, Node/Express API, Python geospatial/ML service, PostgreSQL/PostGIS schema, optional C++ algorithms, and project documentation.

## Current status

This repository intentionally contains placeholders only. No application logic, external datasets, credentials, model files, dependencies, or generated reports are included.

## Planned workflow

1. Select a geographic region on an interactive Earth map.
2. Ingest and validate scientific and geospatial sources.
3. Compute indicators, historical changes, anomalies, habitability factors, and evidence-based prospectivity.
4. Present results with traceable evidence and provider-agnostic AI assistance.

See `docs/architecture.md` for the planned boundaries and responsibilities.
